# Event-B-Based Testing of Cyclic Reactive Systems

Research artifact for the manuscript. Repository: https://github.com/binhtt/CyclicTesting

## Reviewer quick start

Linux, Python 3.12 and GCC; no third-party Python packages are required.

```bash
python3 scripts/verify_integrity.py
python3 experiments/controller/run_all.py
python3 scripts/verify_results.py --controller-run
```

This runs focused interpreter checks, generates tests directly from native Event-B XML, executes the staged C controller and its twelve faulty variants, compares recorded counts, and replays tests on M1. Context axioms, finite parameter domains, guards and simultaneous assignments are interpreted; no controller transition branches are transcribed into Python. The adapter encoding, core projection and schedule policies are configured.

## External benchmarks

```bash
python3 experiments/external/experiment.py
python3 scripts/verify_results.py --external-run
```

The runner retrieves hash-pinned public archives, screens eight DOT/C pairs and mutates only accepted pairs. Recorded accepted pairs are m183 and m159; 45/59 mutants detected (76.27%), with potentially equivalent mutants retained. External results were reproduced in the earlier packaging audit, not rerun for this direct-XML update. They use supplied Mealy models, not Event-B.

## Evidence and limitations

`results/controller-directxml/` contains the new evaluated run. `results/controller/` preserves the earlier manually encoded run for comparison. `results/external/` and `results/formal/` preserve their recorded evidence. Outputs regenerated by the commands live under `experiments/`.

The interpreter supports the finite Event-B subset used by this pilot; it is not a general Event-B implementation and has no general correctness proof. M0/M1 checks use the same interpreter and representative core states, not a proof of refinement or exhaustive refined-graph checking. Tests require an implementation adapter exposing cycle stages. Finite test success is not a correctness proof.

ProB is optional historical analysis: `tools/prob/` and its earlier logs are retained, but ProB is not used by the current generation/execution workflow. No new ProB run is claimed.

Controller provenance: simplified pilot informed by https://github.com/favu100/SimB-examples at commit ebe94030c5e884431917e0eef18c6204af306a00. External provenance: ASML/RERS 2019 public DOT and C archives pinned in experiments/external/sources.json. Upstream archives are not bundled.
